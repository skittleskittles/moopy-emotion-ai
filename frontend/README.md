# Website

## <a href="https://react.dev/" target="_blank">React</a> + <a href="https://www.typescriptlang.org/" target="_blank">TypeScript</a> + <a href="https://tailwindcss.com/" target="_blank">Tailwind</a>.

## How to run

1. Go into project

```bash
cd frontend
```

2. Install dependencies

```bash
npm install
```

3. Run project

```bash
npm run dev
```
